WI-Print — Windows

IMPORTANTE:
- NO copies solo WI-Print.exe suelto.
- Usa el .exe portable (un solo archivo) O la carpeta win-unpacked completa.
- La carpeta debe incluir: WI-Print.exe, resources/, locales/, *.dll

Si no arranca, revisa el log:
  %APPDATA%\WI-Print\logs\boot.log

La app corre en la bandeja (icono junto al reloj, o en "^" iconos ocultos).
