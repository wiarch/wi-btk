WI-BTK — Windows

IMPORTANTE:
- No copies únicamente el ejecutable fuera de su distribución.
- Usa el instalador/portable generado por el proceso de release o la carpeta win-unpacked completa.
- La distribución debe incluir WI-BTK.exe, resources/, locales/ y las DLL necesarias.

Si no arranca, revisa el log:
  %APPDATA%\WI-BTK\logs\boot.log

La aplicación puede ejecutarse en la bandeja del sistema, junto al reloj o en los iconos ocultos.

WI-Rec es el módulo de captura integrado en WI-BTK; no es el nombre del producto completo.
